# 《地铁的另一座城市》先导宣传概念片素材 v01

交付日期：2026-10-12。用途：先导宣传概念片的静态关键帧与图生视频参考，不是正式剧集定稿，也不是完成的视频。

## 本包内容

8 张 PNG：2 张原图无损复制，5 张依据已有分镜进行生成式整理，1 张新增镜像城市生活街道。
另附本说明、素材索引（尺寸/来源/SHA-256）、生成提示词、可点击预览页。原始交接 ZIP 和外部文件未覆盖或改动。

## 使用顺序

推荐初排：01 现实城市 → 02 现实列车 → 03 通勤 → 04 发现异常 → 06 镜像城市 → 05 魔法列车 → 07 抵达 → 08 镜像生活街道 → 片名/可选画外音。
编号是资产编号，不强制镜头顺序或时长。03/04与02/05分别适合建立视觉呼应；不得据此声称视频连续变形已验证。
暂定结尾台词“原来你真的能看见这里。”仍可选择画外音，不因此新增固定伙伴或锁定说话人。

## 本轮已处理

- 主角使用灰色帽衫、浅暖灰外套和黑色背包；通勤与发现异常不再明显变成深色外套。
- 现实/魔法列车统一为现代地铁轮廓、相近观察方向；魔法版保留蓝色、少量黄铜线条和星形装置。
- 分镜被重新表现为独立画面，不含原分镜编号/字幕边框；车头未保留可读站名，避免锁定暂用地名。
- 抵达站厅保持公共交通功能与人物连续性，减少密集装饰，不另引入古典机车型。
- 新增镜像城市普通生活街道：居民购物、店铺、住宅、送货与少量魔法。它是待定街区概念，不代表正式建筑风格、具体站外位置或地图已定。
- 双城大景保留原有内容，用作少量奇观，不代表所有镜像城市场景都如此华丽。

## 实际规格与使用边界

- 7 张为1672×941，03为1659×948；均为横屏，03略偏离16:9。保留生成原始像素，不伪称4K或统一1920×1080。
- 后续可在剪辑中按项目画幅适配；本包没有强行拉伸、上采样或二次压缩原图。
- 生成式整理包含细节重新诠释，不是无损裁切或对原图细节的准确恢复。
- 已目视检查人物基本辨识度、衣装、车体方向、分镜文字与日常场景主题；未作逐像素配准、人物模型绑定或动态视频测试。
- 未继续微调发丝、包扣、建筑细部与远景车型。双城远景列车与近景仍可能存在小差异，概念片可采用独立建立镜头。
- 新生活街区采用朴素石墙/灰泥/砖与街边店铺，提供本版生活尺度对照；不应推导出全城统一为某一现实地域建筑。
- 01/06为完整保留的旧候选原图；背景微小文字及城市细节未逐项修订。任何可见小字不是最终文案。
- 还没有制作视频、声音、字幕或平台发布文件，未进行发布。
