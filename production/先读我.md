# 先读我：Grok Build 先导宣传概念片交接

版本 v01 · 2026-10-12

## 当前目标

用本包制作《地铁的另一座城市》的先导宣传概念片，验证氛围、吸引力和基本叙事。不是正式剧集，不需要先完成世界观百科、角色建模或全季大纲。

本制作包共13张图：8张主选静态关键帧＋5张辅助参考。主选包含2张原图、5张生成式整理图、1张新增镜像生活街道。另有单独的原始交接备份，保存全部23张原始素材；不必与制作包一起导入。

## 如何交接

1. 将本制作包交给接手工具或执行者。若界面不能读取ZIP，解压后先提供“01_主选关键帧”的8张PNG及“给Grok_Build的制作说明.md”。这是通用交接建议，本地尚未验证Grok Build的导入格式与功能。
2. 人物参考不足时再提供R01/R02；其余参考按需要提供。每次生成优先提供当前镜头主图，避免同时喂入所有候选图。
3. 让执行者先核对是否能读取8张主选图，再制定镜头和动态方案。不能读取时明确告知缺失项，不假装已读素材。
4. 没有视频生成或导出能力时，应交付可执行分镜、逐镜提示词和剪辑方案，并清楚报告限制。没有上传、生成或发布成功的证据时不可声称完成。

## 采用顺序与冲突处理

当前用户要求 > 本包制作说明 > 01主选关键帧 > 02辅助参考 > 历史交接说明。
这是本次概念片的使用规则，不代表全剧永久定稿。主角以03/04/07为准，现代地铁车型以02/05为准，双城以01/06为准，镜像日常以08为准。

## 不要混淆

- 人名为周遥，不是周瑶。
- 三视图、表情和道具图仍有用，但不是本片每个特征的统一母版。
- 本片选择浅色外套＋灰色帽衫＋黑色背包；不要因为旧三视图而换成职场装、冒险装或低盘发。
- 镜像世界有居民和日常生活，不是全城宫殿。08就是镜像城市，不是现实世界。
- 旧文件中写有的城市名、年龄细节、身高、魔法道具和台词，不自动视为本片新增定稿。
- 素材均是静态图，没有附带视频、音轨或已验证的镜头运动。
