# 《地铁的另一座城市》｜Work / Codex 交接包 v0.1

当前聊天生成视觉素材的整理包，制作于 2026-10-12。

**一个 ZIP 保存全部当前可用相关内容，避免逐张手工保存。**

## 从哪里开始

1. `handoff/PROJECT_CONTEXT.md`：已确认与未确认的故事和美术设定。
2. `previews/ALL_ASSETS_CONTACT_SHEET.jpg`：全部 23 张素材的缩略总览，带资产 ID。
3. `data/manifest.json`：每张素材的原始文件名、归档路径、尺寸、哈希和状态。
4. `reports/INITIAL_QA_NOTES.md`：目前已知的一致性和质量风险。
5. `handoff/WORK_TASK.md` / `handoff/CODEX_TASK.md`：分别是两个工作模式的任务说明。
6. `assets/`：无损拷贝自当前会话运行环境的 23 张独立 PNG 文件，其中部分 PNG 本身是海报拼贴，不能当作视频独立高清母图。

## 状态说明

- `exploration`：探索设定草图，有启发性，但不代表定稿。
- `candidate`：独立候选素材，须复核一致性。
- `crop_lowres`：从拼图裁切的低分辨率镜头参考。
- `legacy`：与最新地名原则不符的历史概念图，仅作为归档。

**不包括**：两张用户截图（不是作品素材）；与 `黄昏繁华都市交通枢纽.png` 二进制完全重复的临时文件 `imagegen.png`。无丢弃有效内容。

## 项目原则

尊重“少量先做，边做边想”：不可强行把长期主线、结局、城市全名、全部站点定成死规则。当前目标是素材整理与先导片准备，不是全季生成。
