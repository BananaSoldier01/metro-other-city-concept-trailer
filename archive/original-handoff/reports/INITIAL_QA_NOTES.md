# 第一轮素材审查要点（预检，不代替完整视觉审查）

## 必须识别的问题

1. **角色名字**：正确写法始终是「周遥」。原素材有文件名「周瑶角色服装设定集.png」，文件在包内已按周遥命名，`data/manifest.json` 保留原来源追踪。
2. **人物容貌与动漫风格**：多张角色板面部、盘发位置、发束、身材比例、鞋和包细节不完全一致；也存在较偏真人而不够成熟 3D 动画风的成品。需要人工/模型逐张比对，不应假定已满足定妆要求。
3. **服装连续性**：早期周遥穿深色长外套/西装；第三组分镜出现灰色连帽衫等变化。冒险装与两套服装切换时间未定，不得作为同一镜头连续状态直接复用。
4. **列车设定漂移**：镜像魔法列车有带古典蒸汽火车头的方案，也有现代地铁型华丽列车，尚未明确哪款是正式造型。现实列车也待建立统一外观。
5. **真实与镜像地理**：存在概念对照相似构图，但第二组两个独立生成枢纽（CITY-07/CITY-09）尚未严格验证同机位、同道路/轨道/广场分布。不能把“类似景别”误认为“严格同地图”。
6. **海报拼贴不等于母图**：多数早期概念图带排版、标注、文字、拼贴；CITY-05/06 和 TRN-03~06 是 **800x450 或约500px宽的裁切**，明显不足以当正式高清独立素材。
7. **地名与文字**：CITY-01/02 属于旧版现实地名示意，与当前“正式全虚构”方针冲突；其它图的字幕、英文、站牌、标志也需去除或人工复核。`中环站`目前仅工作占位符。
8. **画幅与分辨率**：混有 1536×1024、1672×941、1448×1086 和低清裁切，不应无差别地改名为“16:9高清成片”。

## Work 的首轮建议产出

- 一份素材矩阵：ID、主题、文件尺寸、角色脸是否一致、服装是否一致、场景位置是否一致、是否含不适用的地名/文字、是否适合视频参考、优先整改动作。
- 把候选资产分为：**保留待定 / 需要二次生成 / 构图参考 / 废弃但保留归档**，并给出理由。
- 提出**一次只需少量新生成**的补救计划：优先统一角色定妆、双城固定机位、列车外观，再生成用于视频的关键帧。
- 在新输出目录中创建无损保留原始文件的统一命名版本，并产生最终文件索引、对照预览图、变更记录。

## 审核标准建议

一致性不仅是画风：同一角色的面容骨架、发际线、发型、衣服层次、背包、身高关系要稳定；同一城市地点的主要道路、出入口、轨道弧线、车站建筑位置应当可对应；两套文明应对比明显但不应出现两套独立城市平面图。魔法场景要保留日常功能逻辑，而非只堆尖塔和流光。
