# 《地铁的另一座城市》项目底座与设定状态

**交接日期：2026-10-12**  
**说明：此文档是聊天内容的准确摘要，不是逐字聊天记录。** 若将原聊天移入 ChatGPT 项目，Work 可同时参考原对话。场景概念图均为开发阶段，不代表所有视觉元素已定稿。

## 已确认的方向

- 暂定片名：《地铁的另一座城市》。**不要把旧的推广标语当成已定稿文案**；用户明确否定过“下班后的下一站，是另一个世界。”等过于直白的口号。
- 内容形式：希望用 Grok Imagine 制作抖音/视频号的原创 AI 漫剧，验证起号潜力、合理利用生成额度。作品**倾向 16:9 横屏**，但画幅及单集时长都尚未最终决定。原先讨论过多种时长，不要锁死。
- 题材：都市奇幻、镜像城市、魔法文明、探索与冒险、角色成长。基调为**浪漫奇幻 + 热血冒险**，价值观明确正向；不走恐怖血腥、萌宠、机房或动力行业题材。
- 世界关系：现实是一座普通现代大都市；镜像世界具有**相互对应的城市主干道、主要空间节点和地理骨架**，但拥有**自己的居民、历史、文明、魔法设施、建筑形态**，并非完全 1:1 复制。主城 + 外围区域，铁路贯穿探索。可参考《女神异闻录5》式的现实/异世界对比，但不复制其认知殿堂机制。
- 地名：**不用“南京/新街口”等真实地名作为正式成片设定**。制作中可借鉴现实城市的空间气质，但正式使用虚构城市与地点；两城**核心地名相同或高度近似**以降低观众认知负担。当前“中环站”只是暂用场景名，并非整部作品地名清单定稿。
- 魔法文明：日常魔法普及，高阶魔法稀有；魔法设施/道具与可学习的施法并存。不要继续设计完整魔法等级体系，除非剧本明确需要。
- 主角：**周遥**（重要：是“遥”，不是“瑶”），暂定 28 岁，女，大城市项目运营类职场人；理性谨慎、务实、有责任感，带少量冷幽默；初期不自知地具有能够接触两城的特殊性，隐藏身份/能力可随剧情逐渐披露。人物长期动力从好奇逐渐延伸到关系连接和责任，包括后续可能的利益关联。
- 角色组织：**暂不强行安排固定搭档**，可以在旅途中逐渐结识独立冒险者、居民、列车员等重要人物。
- 剧情组织：保留 **整季长期目标（B）+ 每集完成具体冒险或任务（C）+ 探索新站点/奇观（A）** 的结构意向；“修复失联线路”曾作为候选提议，但其根本原因、持续多少季、长期使命均**未定稿**。先不要把失联铁路当成永久不可更改的设定。
- 美术方向：已选**动漫风**，目标为成熟的 3D 动画电影感，人物自然、奇幻城市壮观；但现存图仍有偏真人的形象，需要做风格统一检查。
- 先导片：已经选综合型（世界观 + 剧情钩子），**45—60秒是试验时长，非正式成片锁定值**；预计包括现实通勤、地铁窗外世界变化、城市镜像对照大场面、奇幻列车和魔法城市第二个大场面。结尾钩子暂定 **“原来你真的能看见这里。”**；不预设说话人必须是固定搭档。
